Kubedog is a library to watch for Kubernetes resources readiness, presence or absence. It also collects Kubernetes Events and logs from Pod's containers.

This library is used in [werf](https://github.com/werf/werf) and [Nelm](https://github.com/werf/nelm) to track resources during deployments.
